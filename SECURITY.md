# Security policy

## Reporting a vulnerability

Please do **not** open a public issue for security problems.

Email: privacy@gettabpillow.fun

Include:

- a short description and impact;
- steps to reproduce;
- extension version and browser version;
- proof of concept or screenshots if available.

We aim to acknowledge reports within 72 hours and to ship a fix as soon as practical.

## Scope

In scope: the TabPillow extension, its permissions, data handling and the website
gettabpillow.fun.

Out of scope: issues in Chrome itself, third-party sites, and social engineering.
