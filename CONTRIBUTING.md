# Contributing

This repository is for documentation and feedback. The extension source code is proprietary, so we
do not accept pull requests that change the product code.

## Bug reports

Use the **Bug report** issue template and include:

- TabPillow version (`chrome://extensions`);
- Chrome version and OS;
- what you expected and what happened;
- steps to reproduce;
- screenshots or a short screen recording if possible.

## Feature requests

Use the **Feature request** template. Describe the problem first, then the proposed solution.
Please avoid generic “make it faster” requests without a scenario.

## Documentation fixes

Typos and clarity fixes in `docs/` are welcome as issues or small pull requests.

## Rules

- Be respectful; no spam or self-promotion.
- Do not post personal data, tokens or browsing history.
- Security issues go to privacy@gettabpillow.fun, not public issues.
